Preparando seu gabinete…

O aplicativo ainda não carregou. Este projeto React precisa ser compilado antes de funcionar.

No GitHub Pages: selecione Settings → Pages → Source → GitHub Actions. Depois execute Actions → Publicar no GitHub Pages → Run workflow e aguarde os passos build e deploy ficarem verdes.

No computador: execute npm install e npm run dev na pasta do projeto; abra a URL mostrada. Abrir o index.html por duplo clique não executa o jogo.

Se o deploy já terminou, atualize a página sem cache e confira se o navegador está bloqueando JavaScript.
